# 3차 — UX·IA 설계

## 원칙

- 모바일 우선
- 로그인 후 본인 담당 건을 우선 표시
- `내 담당 / 전체` 전환 제공
- 영업 건 탐색은 단계 중심
- 회사는 검색 중심의 보조 영역
- 목록에서 상태에 맞는 빠른 행동 제공
- UI 배치와 브랜드 테마는 프레임 목업 검수 이후 확정

## 정보 구조

- 할 일
  - 기한 초과
  - 오늘 할 일
  - 신규 접수
  - 위임받은 건
  - 견적 후 재연락
  - 계산서 발행 예정
  - 미수금 확인
- 영업판
  - 큰 단계 및 세부 상태별 영업 건
- 영업 건
  - 고객·문의, 활동, 다음 행동, 추산 가치, 문서, 계약·청구, 변경 이력
- 계약·청구
  - 계약 금액, 청구 일정, 계산서, 입금, 미수금, 수정·환불
- 회사
  - 회사 정보, PM, 과거·현재 영업 건
- 성과
  - 파이프라인, 가중 예상 수주, 발행 예정, 실제 발행, 실제 입금
- 관리
  - 사용자, 서비스, 확률, 휴가, 제외 상담, 감사 기록, 연동 설정

## 화면별 핵심 목표

| 화면 | 핵심 목표 |
| --- | --- |
| 할 일 | 지금 처리해야 할 연락·후속·청구·미수금 업무를 빠짐없이 실행한다. |
| 영업판 | 단계별 분포와 멈춰 있는 영업 건을 파악한다. |
| 영업 건 상세 | 고객 맥락을 이해하고 연락·위임·기록·다음 행동을 완료한다. |
| 영업 건 추가 | 전화·소개로 들어온 영업 건을 빠르게 등록한다. |
| 회사 | 특정 회사의 전체 영업·계약 이력을 확인한다. |
| 계약·청구 | 계약부터 계산서·입금·수정·환불까지 정확히 관리한다. |
| 성과 | 이번 달 예상 수주·청구·발행·입금을 구분해 판단한다. |
| 관리 | 구성원·서비스·확률·연동 기준을 관리한다. |

## 전체 프레임 목업 화면 범위

대표 화면뿐 아니라 사용자가 업무를 완료할 때 필요한 등록·수정·상세·예외 처리 화면까지 독립 화면으로 검수한다.

| 영역 | 화면 수 | 포함 범위 |
| --- | ---: | --- |
| 접근 | 1 | Google 로그인 |
| 할 일 | 9 | 오늘 할 일, 알림, 기한 초과, 오늘 예정, 신규 접수, 위임, 견적 후 재연락, 계산서 발행, 미수금 |
| 영업 | 12 | 영업판·필터, 직접 추가, 상세, 정보 수정, 활동, 다음 행동, 위임, 상태, 서비스·추산, 문서, 변경 이력 |
| 회사 | 3 | 검색, 상세, 수정 |
| 계약·청구 | 8 | 현황, 계약 등록·상세·수정, 청구 일정, 계산서 상세, 입금, 수정·취소·환불 |
| 성과 | 1 | 월간 성과 |
| 승인 | 2 | 승인 목록, 요청 상세 |
| 관리 | 9 | 관리 홈, 종료·제외, 감사, 사용자, 휴가, AI, 연동, 서비스·확률, 안정성 |
| 검수 | 1 | 전체 화면 검수 인덱스 |
| 합계 | 46 | 모바일 프레임 목업 전체 경로 |

구현 경로와 화면별 목표의 기준은 `apps/web/src/lib/frame-routes.ts`에서 관리한다.

## 상태별 핵심 행동

| 상태 | 핵심 행동 |
| --- | --- |
| 신규·미확인 | 상담 대상 판단 |
| 1차 연락 대기 | 전화, 완료, 위임 |
| 고객 응답 대기 | 응답 기록 |
| 초기 상담 완료 | 다음 행동 실행 |
| 후속 진행 | 행동 완료 |
| 제안·협의 | 금액·확률 조정, 계약 전환 |
| 계약 | 계약 금액과 청구 일정 등록 |
| 계산서·입금 | 발행·입금·수정·환불 기록 |
| 장기 보류 | 재개 또는 실패 처리 |
| 실패·제외 | 열람 또는 재활성화 |

## 성과 계산

- 전체 파이프라인 가치: 진행 건의 추산 가치 합계
- 가중 예상 수주액: 이번 달 예상 계약 건의 `서비스별 추산 가치 × 성공 확률`
- 청구 예정액: 이번 달 발행 예정 계산서 금액
- 실제 발행액: 이번 달 유효 계산서 발행액
- 순발행액: 실제 발행액 − 취소·환불액
- 실제 입금액: 이번 달 실제 입금액
- 미수금: 유효 계산서 발행액 − 실제 입금액
