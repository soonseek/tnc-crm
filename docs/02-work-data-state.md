# 2차 — 업무·데이터·상태 정의

## 업무 흐름

1. 텔레그램으로 신규 상담 전체 내용을 받는다.
2. 상담 내용을 확인한다.
3. 즉시 확인했더라도 일반적으로 5~10분 뒤 연락한다.
4. 서비스 오인 문의는 사유를 선택하고 제외한다.
5. 유효 상담은 기본적으로 본인에게 배정한다.
6. 직접 처리하기 어려우면 대표님에게 위임한다.
7. 통화 성공 시 배경과 요구를 파악하고 다음 행동을 등록한다.
8. 통화 실패 시 즉시 문자를 남기고 고객 응답 대기로 전환한다.
9. 연락 결과와 다음 행동을 기록한다.

### 연락 시간과 기한

- 전화 가능 시간: 업무일 오전 9시~오후 6시
- 업무시간 내 접수: 접수 시각으로부터 1영업일
- 업무시간 외 접수: 다음 영업일 오후 6시
- 주말·대한민국 공휴일 제외
- 위임해도 원래 기한 유지

## 데이터 원칙

- Emergent: 고객이 제출한 원본 상담의 기준
- CRM: 수정 연락처, 담당자, 활동, 상태, 계약, 청구, 입금의 기준
- 기존 엑셀은 폐기
- 같은 회사의 여러 문의는 별도 영업 건으로 보존하고 회사 아래 연결
- 회사 식별 기본값은 회사명
- 모든 수정자·수정 시각·변경 전후 값 보존
- 제외·실패 데이터는 삭제하지 않고 기본 목록에서 숨김

## 주요 데이터

### 회사

- 회사명
- 회사 규모: 1~10명, 11~50명, 51~200명, 201~500명, 500명 이상
- PM: 등록된 구성원 중 한 명

### 영업 건

- 접수 일시, 연락 기한, 고객 담당자명·직함, 연락처, 이메일, 고객 메모
- 영업 담당자, 큰 단계, 세부 상태, 상담 요약, 비고
- 관심 서비스, 서비스별 추산 가치, 전체 추산 가치
- 성공 확률, 예상 계약 월
- 다음 행동, 담당자, 예정일
- 투입 인력

### 서비스

- 집합교육
- 온라인 1:1 코칭
- AX 구축 서비스
- 3개월 변화관리 컨설팅

한 영업 건에서 복수 선택할 수 있으며 변화관리 컨설팅은 단독 판매도 가능하다.

### 계약·청구

- 서비스별 계약 금액, 부가세 포함
- 청구 구분: 선금·중도금·잔금·기타
- 예정 발행일, 지급 비율 또는 예정 금액
- 실제 발행일·금액
- 입금 예정일·실제 입금일·실제 입금액
- 계산서 취소·수정, 환불
- 청구 비율 합계 100% 검증
- 계산서 하나는 하나의 서비스에 연결
- 부분 입금 없음

## 상태 모델

영업 건은 `큰 단계 + 세부 상태`로 관리한다. 담당자, 위임, 기한 초과는 상태가 아니라 별도 속성이다.

| 큰 단계 | 세부 상태 |
| --- | --- |
| 신규 | 미확인, 1차 연락 대기 |
| 초기 상담 | 고객 응답 대기, 초기 상담 완료 |
| 후속 진행 | 미팅 일정 확정, 미팅 완료, 회사소개서 발송 완료, 샘플 견적 발송 완료, 제안 대응 완료, 세미나 일정 확정 |
| 제안·협의 | 정식 제안·견적 발송 완료, 협의 중 |
| 계약 | 계약서 송부, 계약서 서명 완료, 계산서 발행 |
| 보류 | 장기 보류 |
| 종료 | 계약 실패, 상담 대상 제외 |

### 자동 전환

- 다음 행동 완료 → 해당 행동 완료 상태
- 고객 응답 대기 후 3개월 무활동 → 장기 보류
- 첫 번째 유효 계산서 발행 → 영업 성공 100%
- 장기 보류·실패·제외는 관리자가 재활성화 가능

### 보수적 기본 성공 확률

| 단계 | 확률 |
| --- | ---: |
| 신규 | 0% |
| 초기 상담 | 5% |
| 후속 진행 | 10% |
| 제안·견적 | 20% |
| 협의 중 | 40% |
| 계약서 송부 | 60% |
| 계약서 서명 완료 | 80% |
| 첫 유효 계산서 발행 | 100% |
| 장기 보류·실패·제외 | 0% |
